# Security Policy

## Supported Versions

This project is a private local overlay application. Security fixes target
the current `main` branch and the latest tagged release.

## Scope

Report defects in this repository's TypeScript server, overlay, QML mod,
installer scripts, policy tooling, workflows, and configuration. Do not put
credentials, private user data, or exploit details in a public issue.

## Reporting a Vulnerability

Use GitHub private vulnerability reporting when enabled. Otherwise contact the
repository maintainers through a private channel associated with the project.
Include the affected path, reproduction conditions, impact, and a safe
verification method. Do not include secrets or live user data.

## Disclosure

Keep reports private while maintainers verify and remediate the issue. Agree
on disclosure timing with the reporter after a fix is available.
